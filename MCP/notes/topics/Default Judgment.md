# Default Judgment

Available where a defendant fails to enter an appearance to defend (or, having entered one, is subsequently barred — see [[Notice of Bar]]).

## Documents required

Consistent across every memo that tests it:
- Original **Summons**
- Original **Return of Service**
- Original and one copy of the **Request for Default Judgment**
- A **Damages Affidavit** (where the claim is not for a fixed liquidated amount, e.g. motor vehicle accident damages)

Where the claim is **not** for damages and the defendant fails to enter an appearance to defend, simply request default judgment and file a damages affidavit only if necessary. [[MCP 2010-12-15 Special Supp]] Q1h

## Distinguish

- **Default judgment** — undefended (no appearance to defend, or barred).
- **[[Rule 14 Judgment|Summary Judgment (Rule 14)]]** — defended, but no bona fide defence.
- **[[Provisional Sentence]]** — liquid document, onus on the defendant to resist.
