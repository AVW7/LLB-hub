# Second Brain Setup

## For future agent

Local second-brain integration for the existing LLB Hub. Setup status is tracked separately from archive content.

## State

Vault structure and local plugin configuration created. Model installation and initial indexing are tracked in `.brain/setup-status.json`.

## Use

1. Open this folder as an Obsidian vault.
2. Open the LLB Second Brain plugin and run its Notes indexing command.
3. Use Notes chat to retrieve cited archive material.
4. Save new notes explicitly.

## Boundaries

Existing subject documents and authored notes retain their paths and content. Original material stays in its subject folder. Local processing uses Ollama; no cloud fallback is configured.
